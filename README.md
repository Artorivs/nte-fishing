# NTE Auto-Fishing Bot / NTE 自動釣魚機器人

## English version

A macOS Python bot for the fishing minigame in *Neverness to Everness* (NTE). It watches the reeling bar (green zone + yellow marker) on screen using color detection and taps **A/D** to keep the marker centered, while periodically tapping **F** to cast and start reeling.

⚠️ **Disclaimer:** Automating gameplay like this might violates the game's Terms of Service. Use at your own risk with regard to your account.

---

### Files

| File | Purpose |
| --- | --- |
| `fish_bot.py` | The bot itself. Casts, waits for a bite, reels in by nudging A/D. |
| `calibrate.py` | Interactive tool to select the bar's screen region and sample its colors. Run once per lighting condition (see below). |
| `debug_capture.py` | Diagnostic tool — captures exactly what the bot sees and reports whether it's detecting the bar correctly. |
| `config.json` | Saved region + color ranges, generated by `calibrate.py`. |
| `requirements.txt` | Python package dependencies. |

---

### Setup

1. **Install Python packages:**

   ```bash
   pip3 install -r requirements.txt
   ```

2. **Grant macOS permissions** to your terminal app (Terminal/iTerm/etc.) under **System Settings → Privacy & Security**:
   - **Screen Recording** — required for the bot to see the game.
   - **Accessibility** — required for the bot to send A/D/F key presses and register hotkeys.

   Restart the terminal app after granting these.

3. **Calibrate** (skip if `config.json` already matches your setup):
   - Get a fish on the line so the reeling bar is visible.
   - Run `python3 calibrate.py`.
   - Drag a box tightly around the bar, press ENTER.
   - Click the green zone, then the yellow marker, then press `q`.
   - This saves `config.json`.

4. **Calibrate for day AND night** (recommended):
   The bar is a semi-transparent overlay, so its color shifts slightly with the sky behind it. Run `calibrate.py` once during the day and once at night — it will detect the existing `config.json` and ask to **merge** the new samples in, widening the accepted color range instead of overwriting it. Repeat for any other lighting extremes (dawn, storms, indoors) if needed.

---

### Running the bot

```bash
python3 fish_bot.py
```

- Click into the game window so it has focus.
- **F8** — start / pause the bot.
- **F9** — quit.

The bot alternates between two states automatically:

- **Idle/waiting:** taps F every ~1.5s to cast or trigger the reel-start prompt.
- **Reeling:** once it detects the green zone + yellow marker on screen, it holds A or D to keep the marker centered until the bar disappears (fish caught, escaped, or line broke), then goes back to idle.

---

### Troubleshooting

- **Bot keeps tapping F, never switches to A/D:** Run `python3 debug_capture.py` while the bar is visible. It saves `debug_full_region.png` plus mask images and prints pixel counts — this tells you whether the problem is the captured region (wrong area / blank due to missing Screen Recording permission) or the color ranges (need recalibration).
- **Captured image looks black or blank:** Screen Recording permission isn't granted, or the terminal app needs a restart after granting it.
- **A/D presses don't reach the game:** Accessibility permission isn't granted, or the game window doesn't have focus.
- **Works sometimes, not others (e.g. day vs night):** Recalibrate under the lighting condition that's failing — see "Calibrate for day AND night" above.

---

### Tuning

Adjust these constants near the top of `fish_bot.py` if the marker overshoots/oscillates or reacts too slowly:

- `KEY_TAP_SECONDS` — how long each A/D correction tap is held.
- `DEAD_ZONE_PX` — how close to center the marker must be before the bot stops correcting.
- `REEL_LOOP_HZ` / `IDLE_LOOP_HZ` — how often the bot samples the screen in each state.
- `CAST_RETRY_SECONDS` — how often it re-taps F while idle.

## 安裝設定

1. **安裝 Python 套件：**

   ```bash
   pip3 install -r requirements.txt
   ```

2. **授予 macOS 權限**：前往 **系統設定 → 隱私權與安全性**，為你使用的終端機應用程式（Terminal / iTerm 等）開啟：
   - **螢幕錄製**——機器人需要靠這個「看到」遊戲畫面。
   - **輔助使用**——機器人需要靠這個送出 A/D/F 按鍵以及註冊快捷鍵。

   授權後請重新啟動終端機應用程式。

3. **執行校正**（若 `config.json` 已經符合你的設定，可略過此步驟）：
   - 讓魚上鉤，使收線條顯示在畫面上。
   - 執行 `python3 calibrate.py`。
   - 用滑鼠框選收線條的範圍，按 ENTER 確認。
   - 依序點擊綠色區域、黃色標記，再按 `q`。
   - 這會將設定儲存到 `config.json`。

4. **建議同時針對白天與夜晚各校正一次：**
   收線條是半透明的介面疊層，顏色會隨背景天空亮度而略有變化。請在白天執行一次 `calibrate.py`，晚上再執行一次——程式會偵測到已存在的 `config.json`，並詢問是否要**合併**新取樣的顏色範圍（而不是直接覆蓋），藉此擴大可辨識的顏色範圍。若有其他明顯不同的光線環境（黎明、暴風雨、室內等），也可以比照辦理。

## 執行機器人

```bash
python3 fish_bot.py
```

- 先點擊遊戲視窗，讓它取得焦點。
- **F8**——啟動／暫停機器人。
- **F9**——結束程式。

機器人會在兩種狀態間自動切換：

- **待機／等待中：** 每隔約 1.5 秒按一次 F，用來拋竿或觸發「開始收線」的提示。
- **收線中：** 一旦偵測到畫面上出現綠色區域與黃色標記，就會按住 A 或 D 讓標記保持置中，直到收線條消失（魚被釣起、逃脫，或斷線），之後回到待機狀態。

---

## 疑難排解

- **機器人一直按 F，始終沒有切換成 A/D：** 在收線條顯示時執行 `python3 debug_capture.py`。它會儲存 `debug_full_region.png` 以及遮罩圖片，並印出像素數量，藉此判斷問題出在擷取區域（區域錯誤，或因未授權螢幕錄製而畫面全黑），還是顏色範圍需要重新校正。
- **擷取到的畫面是黑色或空白：** 尚未授權螢幕錄製權限，或授權後尚未重新啟動終端機應用程式。
- **A/D 按鍵沒有傳送到遊戲：** 尚未授權輔助使用權限，或遊戲視窗未取得焦點。
- **有時候可以正常運作，有時候不行（例如白天／夜晚差異）：** 請針對失效的光線條件重新校正，作法請參考上方「建議同時針對白天與夜晚各校正一次」。

## 參數調整

若標記過衝／來回震盪，或反應太慢，可調整 `fish_bot.py` 檔案開頭附近的以下常數：

- `KEY_TAP_SECONDS`——每次 A/D 修正按鍵按住的時間長度。
- `DEAD_ZONE_PX`——標記需要多接近中央才會停止修正。
- `REEL_LOOP_HZ` / `IDLE_LOOP_HZ`——機器人在各狀態下擷取畫面的頻率。
- `CAST_RETRY_SECONDS`——待機狀態下重複按 F 的間隔時間。
